Frontier — rendering proof

Every image, GIF and MP4 on this page was produced in this sandbox by CPU reference renderers that read the project's own headers. Nothing here is a screenshot of the Vulkan app, and nothing is a placeholder: the GPU side of the pipeline is simulated on the CPU, exactly as asked.

Read this before you trust any pixel here.
  • Project-Zero images come from Projects/Project-Zero/bin/Project-Zero-CpuReference — the project's own CPU ReSTIR path tracer. Same scene, same sky, same fog, same ReSTIR DI + GI. It is not the Vulkan renderer, so it proves the scene, lighting and integrator are right, not the GPU passes.
  • Project-Drive images come from the new DriveRender CPU reference. It emits the course from DriveCourse.h::EmitCourseTriangles (the very emitter the render side uses), the car body from ControlVehicleMesh.inl, the rims and tyres from ControlVehicleRimMesh.inl / ControlVehicleTyreMesh.inl, and poses all of it from the real VehicleSolver. Shading is a small CPU path tracer I wrote for this proof, not the engine's material model — so the pose, geometry and layout are the project's, the surface shading is not.
  • The code fixes themselves are still GPU-unverified. This sandbox has no GPU and no Windows. The fix work is compile/syntax-checked and now ships the logs that will tell you, on your machine, whether it worked.
