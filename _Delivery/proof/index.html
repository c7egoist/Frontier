Read this before you trust any pixel here.
  • No GPU, no Windows here. The code fixes are compile/syntax-checked only.
  • Distance Field GI — transport, cards, field composition, shadow march, MIS and the bilateral resolve are the engine's. The material is a stand-in Lambert + Schlick/GGX, not the engine's OpenPBR stack.
  • A moved instance does not donate GI. Its baked facets are masked from every exact query, so a moving object is lit by the scene's cards and it occludes — but it never bleeds its own colour. That is the engine's rule as written, faithfully reproduced.
  • Project-Drive — geometry, layout and dynamics are the project's own; surface shading is mine.
The two headline numbers.
  Is it dynamic? Yes. The field is baked once (10,096,972 bytes, 566 ms); moving both objects rewrites 336 bytes and takes 0.001–0.002 ms, and the atlas checksum is identical in all 16 frames. On floor pixels no object ever crosses, the shading moves 6.1× more than when the field is frozen.
  Is it right? Floor RMS against a 4-bounce path trace: 0.130 with the field re-placed, 0.186 frozen, 0.196 with GI off.
And the XPBD finding from the tumble. On a hard landing the soft tyre puts 998 kN through one wheel in a single 240 Hz step — 313× the static wheel load — while the per-node contact λ stays at 0.0016. With h = 1/(240×8) s that is ~5.9 kN per node from λ/h², summed over ~400 nodes with no clamp. See _Delivery/PROOF.md §4.

Distance Field GI — the real pipeline, on moving objects

Four passes, translated line by line from the engine's Slang: capture surface cards, propagate radiance over the card atlas, gather by marching the COMPOSED LOCAL DISTANCE FIELDS, resolve with a 7x7 bilateral filter. Primary visibility is a z-buffer. No path tracing. A sphere orbits and a box spins; the field is baked ONCE and only its 3x112-byte placement rows are rewritten each frame.

Distance Field GI — is it actually right? and is it actually dynamic?

Left: RMS on the floor against a 4-bounce path trace of the identical live geometry. Re-placing the field is the most accurate of the three (0.130 vs 0.186 frozen vs 0.196 GI-off). Right: how much the floor's shading moves between frames, measured only on floor pixels no object ever slides across — so the only thing that can change them is light. Dynamic moves 6.1x more than frozen.
