# Claude instructions for Frontier

## Experimental Remastered UI work

Before creating or changing reusable UI components or studio interfaces under `Experimental Remastered/`, read the [Experimental Remastered UI Component Guidelines](Experimental%20Remastered/UI_COMPONENT_GUIDELINES.md).

Use **Vehicle Lab** (`Experimental Remastered/AssetInspector/`) as the reference for the Outliner / Stage / Inspector composition, compact technical controls, component-status affordances, and legible exterior diagnostics. Follow the guidelines rather than copying Vehicle Lab's vehicle-specific controls or replacing a studio's existing engine and workflows.
