Reference

Controls & data

Navigation

Left-drag orbits, right-drag pans, scroll zooms. Use the top view pills for iso, topographic and section cameras.

Shortcuts

1–3 switch fields, Space play/pause, R reset camera, ? opens this panel.

CSV format

Regular grid with x,y,z,u,v,w columns and optional scalar. Aliases such as vx/vy/vz and semicolon/tab separators are accepted.

JSON format

dimensions:[nx,ny,nz] plus separate u/v/w arrays, row vectors, or a flat data array. Optional scalar arrays are preserved.

GPU path

Arrow and tracer origins advect through the field in vertex shaders every frame, driven by simulation time. Terrain and scalar channels are shader-evaluated; imported grids use Float32 3D textures.

Analysis

Probe, histogram, scalar slices and coherence are CPU-sampled from the same field functions for reproducible readouts and CSV/JSON export.
