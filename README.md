# Frontier

Game project. Currently: research + working prototype for the **real-time non-FFT ocean
simulation** (adaptive 2D column simulation with block-quadtree AMR, WebGPU).

- `docs/OCEAN_SIMULATION_RESEARCH.md` — technique survey, architecture decision, references.
- `ocean/` — runnable WebGPU prototype (see `ocean/README.md`). `npm install && npm run dev`.
