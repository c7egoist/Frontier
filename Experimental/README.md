# Experimental

Contains the interactive **VehicleProvingGrounds** (VehicleHMI) WebGPU + Jolt Physics demo extracted from `https://github.com/c7egoist/Frontier/tree/arena%2Fd3dbcc83-frontier` (commit `6e8005cf`, path `Experimental/SlateReference/A/Exhibits/VehicleProvingGrounds`), extended with the **D-Day Assault (`dday`)** combat level.

## Quick start

```bash
cd Experimental/VehicleProvingGrounds
npm install
npm run serve
```

Then open `http://localhost:8080/` (or `http://localhost:8080/?level=dday`).
